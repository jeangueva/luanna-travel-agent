== Description ==
Luanna muestra a tus clientes vuelos hasta tu ciudad y hoteles cerca de ti, con tus colores.
Es gratis: Luanna gana una comisión de aerolíneas y hoteles cuando tus clientes reservan. A ellos no les cuesta más.

== Installation ==
1. Sube la carpeta `luanna` a `/wp-content/plugins/` o instala el .zip desde Plugins > Añadir nuevo.
2. Actívalo.
3. En Ajustes > Luanna, pega el id de tu sede.
4. Escribe `[luanna]` donde quieras mostrarlo.
